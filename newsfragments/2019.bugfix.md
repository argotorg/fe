The language server now shows signature help for function calls, such as `plain(1, 2)`, `Point::new(1, 2)` or a call through a `use`d path, for trait method calls, and for calls in a contract's `init` and recv arms. Signature help is for the call whose argument list holds the cursor, and its highlighted parameter no longer counts a method's `self` as the first argument or stops at the arguments written so far, as in `plain(1, )`. Call hierarchy no longer lists a call of a closure as a call of `Fn::call`.
