Added non-reverting token helpers that return a classified `std::evm::TokenCall` outcome (`Ok`, `Reverted`, `BadReturn`, `NoCode`) so callers can raise their own errors: `erc20::try_transfer`, `try_transfer_from` and `try_approve` (Solady/OpenZeppelin semantics, bounded 32-byte returndata copy), plus the new `std::evm::erc721::try_transfer_from` and `std::evm::erc1155::try_safe_transfer_from` / `try_safe_batch_transfer_from`. `erc721::check_on_received` classifies an `onERC721Received` hook as a `ReceiverCheck` (`Accepted`, `WrongMagic`, `BadReturn`, `Reverted`, `NoCode`).
