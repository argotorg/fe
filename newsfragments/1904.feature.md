With the `wasm` Cargo feature, `fe build --backend wasm` compiles a file to a WebAssembly module (one linear memory, 32-bit `usize`) and a manifest of its imports and exports. Every non-generic `pub fn` at the root of the file is an export; besides `bool` and integers of at most 64 bits, an export can take `std::wasm::HostText` and return `std::wasm::Reply`, and `extern` functions become imports. `fe test --backend wasm` runs each test as its own module under Node.js. `std::wasm` provides the root effect `std::wasm::Host`, whose capabilities `Log`, `Clock`, `Abort` and the read-only files contract `Files` exports and tests take in `uses`, and pure Fe mocks of each. See "WebAssembly output" in `CLI.md`.
