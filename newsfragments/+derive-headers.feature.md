Code can be generated from the structure of a type at compile time. A provider is a type that implements `Derive`; its `derive` function reads the fields of a struct, or the variants of an enum, through `core::meta` and returns code written with `quote { .. }`, in which `${..}` inserts values and other code. A header, an implementation written with `with (Provider)` in place of a body, asks for that code: `impl Type with (Provider)` adds inherent members, and `impl Trait for Type with (Provider)` implements a trait, including its associated constants and types. A block `with (Provider) { .. }` uses the provider for the goals of a trait of its own package that are proved inside it. Every field of the target must be visible where a request is written. The generated code is checked like written code. See `docs/language/generation.md`.
