A struct field whose array length uses const generic arithmetic, such as `[G1; N + 1]`, now checks against the concrete length when the struct is instantiated, so `Vk<1> { ic: [a, b] }` type checks. If the arithmetic fails for the given arguments, such as `N - 1` at `N = 0`, the initializer now reports an error at the field. Before, the invalid type was accepted.
