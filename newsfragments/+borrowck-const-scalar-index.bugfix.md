The borrow checker now treats a named integer constant like the literal it names when it compares with it, indexes with it or passes it to a call. Before, `i == ONE` or `i >= ONE` related `i` to an unknown value, so `values[i]` and `values[ONE]` (or `values[1]`, or an element borrowed through `elem(mut values, ONE)`) were reported as a borrow conflict even after the overlapping case had returned, and a long `if action == A0 ... else if action == An` dispatch whose branches assert on `action` (for example `if action == 7 { revert(()) }`) took minutes and tens of GB of memory to check, growing exponentially with the number of branches.
