Added `std::evm::layout` with Solidity's storage slot derivations: `mapping_slot(root, key)` for a mapping's entry, `array_data_slot(root)` for a dynamic array's elements and a long `bytes` or `string`'s data, and `element_location` for an element laid out in lanes or whole slots from a first slot. A library collection's `StateIndex::locate` can return `Location { slot: mapping_slot(root, key), offset: 0 }`.
