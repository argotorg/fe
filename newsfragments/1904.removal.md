`DynString` owns its allocation and frees it when dropped, so strings no longer leak on native and WebAssembly targets. It is no longer `Copy`: use `clone()` for a second string, or a view parameter to read one without moving it. `DynString::as_bytes`, whose result outlived the string, is removed, and `DynString::from_abi_tail` now takes ownership of the allocation it is given. Fixed arrays encode and decode without `T: Copy`, and `DynArray::from_slice` takes `T: Clone`.
