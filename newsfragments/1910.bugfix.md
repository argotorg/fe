Const bodies in a generic parameter's default no longer crash the compiler when the owner has a bound naming that parameter or a later one, such as `T: Has<1>` for `trait Has<const N: usize, const L: usize = { N }>`, or when the body is nested in the default, such as the array length in `const L: usize = { let a: [u8; { N + 1 }] = [0; N + 1]; N + 1 }`. A default that reads something only a bound on a later parameter provides is now rejected where it is declared.
