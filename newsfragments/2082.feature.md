Integers have `checked_add`, `checked_sub`, `checked_mul`, `checked_div` and `checked_rem`, which return `None` exactly where the operator would panic (on overflow, including a signed `MIN / -1`, and on a zero divisor) and the operator's result otherwise, so `MIN.checked_rem(-1)` is `Some(0)`, as `MIN % -1` is `0`. They also have `overflowing_add`, `overflowing_sub` and `overflowing_mul`, which return the wrapped result and whether the operation overflowed. They are the methods of `core::ops::CheckedAdd`, `OverflowingAdd` and the like, and work in constants too. `a.checked_add(b)` compiles to the same add with an overflow flag as `a + b`, testing the flag instead of panicking.
