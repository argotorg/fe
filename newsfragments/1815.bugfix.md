Find references, rename, highlighting, code lens reference counts and the SCIP and LSIF indexes no longer take a name bound in a function body for an item. `self` in a method was recorded as a reference to the module around it, a parameter as a reference to a module of the same name, and a closure parameter, effect or contract `init` parameter as a reference to any item of the same name, so renaming a function with that name rewrote it. The code generated for a `msg`'s variants also added references to the `msg` at the variant names. Semantic highlighting now colors these names, and `let` bindings, as variables; it colored `self` as a module and a parameter as a function.
