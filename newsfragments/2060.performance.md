WebAssembly modules run 256-bit multiplication, `addmod`, division by powers of two, byte-order conversions of 64-, 128- and 256-bit integers and loads and stores of fields faster: fevm runs its benchmarks in about 2.4 times its native time in Node.js. At `-O s`, a `match` on an integer whose arms all call a function in tail position with the same arguments is one indirect tail call through a table, which makes an interpreter's dispatch much smaller. Native code at `-O s` now compiles dense `match`es on integers to jump tables, as at `-O1` and `-O2`.
