Code after an `if`/`else` chain or a `match` no longer gets skipped when the last branch diverges (with `return`, `continue` or `break`) but an earlier branch falls through, such as `if a { return 1 } else if b { r = 3 } else { return 2 }` followed by more statements. The chain was typed as diverging, so the code after it was compiled as unreachable and execution reverted or trapped.
