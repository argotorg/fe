Added `std::abi::ArrayView`, a lazy view of a Solidity ABI `T[]` over calldata or any other `ByteInput`, created with `CallData::array_view` or `decode_array_view_at`. It validates offsets and lengths like a Solidity `T[] calldata` parameter and decodes elements one at a time with `get`, with zero-copy `bytes_at`/`string_at` and nested `array_at` accessors, so raw-selector `recv` arms can read large arrays without decoding them into memory.
