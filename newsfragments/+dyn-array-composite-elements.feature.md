`DynArray::get` now works for every ABI element type, including multi-word static structs and tuples and dynamic elements such as `Bytes`. `MemVec` accepts any static ABI element type. The new `std::abi::dyn_array_from([..])` builds a `DynArray` from a fixed array of any element type (for example a `bytes[]`), and `std::abi::canonical_dyn_array` re-encodes a decoded array in canonical layout.
