The alternatives of a `|` pattern may bind names, as in `E::A { x, .. } | E::B { x, .. } => x`, when each binds the same names with the same types and binding modes. A `match` arm may bind an access at a different part in each alternative; elsewhere (`if let`, `while let`, `let`, `let ... else`, `for`) an access must reach the same part in every alternative. New errors report a name missing from an alternative, differing types or binding modes, and such an access. See `docs/language/patterns.md`.
