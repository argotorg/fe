Added `std::evm::rlp` for Recursive Length Prefix encoding, the serialization of Ethereum transactions and trie nodes. `encode_bytes`, `encode_uint`, `encode_address`, `encode_bool` and `encode_list` (of already encoded items) build `Bytes`, and `decode` reads an `Item` in place, whose `as_bytes`, `as_uint`, `as_address`, `as_bool` and `items` accessors return `None` for the wrong kind of item. Decoding accepts only canonical encodings.
