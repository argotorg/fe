Contracts with the same name in different modules of one ingot can be built and tested. When a name is shared, the artifacts are named by module path, for example `lib__a__C.bin`; `--contract` accepts that name, or a source name that only one contract has. Same-named tests in different modules each run their own code. `settings.compilationTarget` in metadata records the contract's path in its source file, such as `inner::C`.
