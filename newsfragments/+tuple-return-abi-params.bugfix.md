Fix the Solidity ABI encoding of `msg` variants that return a tuple with dynamic elements, such as `-> (DynString, Bytes32, Address)`. The return value is now encoded as a parameter list, like the values of a Solidity function with multiple return values (`returns (string, bytes32, address)`), instead of as a single tuple behind an extra leading offset word. Typed calls and `std::abi::sol::decode_output` decode tuple returns the same way, and the generated JSON ABI lists one output per tuple element. This changes the returndata of dynamic tuple returns; static tuples encode the same bytes as before. A single dynamic return such as `-> DynString` or an `#[abi]` struct is unchanged.
