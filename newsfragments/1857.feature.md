A trait implementation can be given a name, as in `impl Price for Item as Wholesale`, and chosen for a block with `with (Wholesale) { .. }`. A named implementation is never selected implicitly. Inside the block it answers every matching trait goal, through generic calls, closures, trait-keyed effect providers and storage indexing, while code that does not declare the bound keeps the ordinary implementation. `with (<Item as Price>)` opens the ordinary implementation, for example inside a named one. A named implementation must agree with the ordinary implementation on associated types, constants and effect rows, and `pub impl` makes its name public. One `with` gives each trait goal at most one implementation, and `Copy`, `Drop`, `Snapshot`, `Pinned` and `ErrorVariant` cannot have named implementations. See `docs/language/named-implementations.md`.
