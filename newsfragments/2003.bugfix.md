The language server now applies `didOpen`, `didChange` and file watcher notifications in the order they arrive, so a request that follows sees the change. Files outside every ingot are reported with the severity of a hint instead of a warning. `fe lsp tcp` listens on 127.0.0.1 unless `--host` is given, keeps serving after a connection is reset before it is accepted, and exits after `--timeout` seconds without clients. The language server no longer panics on a document without a file name, a manifest in a directory that does not exist, a missing current directory, or a dependency cycle that an ingot does not reach.
