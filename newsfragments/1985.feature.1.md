A WebAssembly module now passes the revert data of a panic to its host instead of trapping. Overflow, division by zero, a failed `assert!` and an index outside an array call the import `__fe_revert(address, length)` with Solidity `Panic(uint256)` data, and `assert!` with a message passes `Error(string)` data. A module with no memory left for the data calls the import `abort()`. `examples/wasm/host.mjs` throws a `GuestRevert` with the data and its decoded reason. These imports, `sys_wasm_files_read` and the `stack_top` export make version 3 of the host contract.
