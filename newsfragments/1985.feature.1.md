A WebAssembly module now passes the revert data of a panic to its host instead of trapping. Overflow, division by zero, a failed `assert!` and an index outside an array call the import `__fe_revert(address, length)` with Solidity `Panic(uint256)` data, and `assert!` with a message passes `Error(string)` data. The data of a constant code is a constant of the module, and a module with no memory left for other data calls the import `abort()`. `examples/wasm/host.mjs` throws a `GuestRevert` with the data and its decoded reason. A failed call frees nothing it allocated, so a host makes a new instance of the module after one, as `host.mjs` does. These imports, `sys_wasm_files_read` and the new instance after a failure make version 3 of the host contract.
