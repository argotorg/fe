`core::text` parsers and `std::evm::parse_address` accept any `core::text::Text`, implemented for `String<N>`, `DynString`, `MemSpan`, `MemBuffer` and `std::env::Arg`, so a process argument or a JSON string can be parsed without copying it: `parse_uint(args.get(1))`.

`MemSpan` gains `starts_with`, `ends_with`, `index_of`, `trim`, `split` and `lines`: `for line in input.span().lines() { .. }`. `split` takes a byte or a literal of up to 31 bytes. `lines` and `split(b',')` also work with `enumerate` and `take`; an inline literal separator followed by either doesn't compile yet, so bind it with `let` or use a byte.
