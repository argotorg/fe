`core::text` parsers and `std::evm::parse_address` accept any `core::text::Text`, implemented for `String<N>`, `DynString`, `MemSpan`, `MemBuffer` and `std::env::Arg`, so a process argument or a JSON string can be parsed without copying it: `parse_uint(args.get(1))`.

`MemSpan` gains `starts_with`, `ends_with`, `index_of`, `trim`, `split` and `lines`. `split` and `lines` work in `for` loops and with `enumerate` and `take`: `for line in input.span().lines() { .. }`.
