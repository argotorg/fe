The unsafe-code trust check now follows code that runs without a written call: the `Decode` and `Encode` implementations that a contract's dispatcher applies to the arguments and return value of a `recv` arm and to the arguments of `init`, the `Drop` implementations that run where a value goes out of scope, and a `#[test]` function that an untrusted package contributed to. An `unsafe impl` with no function is judged where it is declared. A dependency without `allow_unsafe` could run unsafe code through these routes without the error that a direct call gives.
