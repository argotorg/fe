An operator after an `if`/`else` expression now applies to the whole conditional, so `if c { 1 } else { 2 } + 3` evaluates to 4 or 5. Before, the operator was parsed into the `else` branch, so the expression silently computed `if c { 1 } else { 2 + 3 }`, and indexing a conditional, as in `if c { a } else { b }[1]`, failed to type check.
