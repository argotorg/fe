A pattern naming a constant that isn't an integer or `bool`, such as a struct, enum or string constant, is now an error (8-0154), as is one whose value depends on generic parameters, like `T::C` (8-0155). A constant that fails to evaluate is now reported at each pattern that names it, like `G<0>::C` with `const C: u256 = 1 / N`; one whose definition is invalid or depends on the pattern itself is 8-0156. In a `match` these patterns failed later in compilation. In a `let`, a parameter or a recv arm they were accepted and matched anything: a recv arm `V { pair: FIXED }` ran for every `V`.
