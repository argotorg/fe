Array repeat lengths and array types computed from generic parameters, such as `[0; N + 1]`, `[0; word_len(N)]`, `[u8; T::LEN]` or a conditional over `N`, are now accepted. Such a length has one type wherever it is written, including across functions with different bounds and across ingots, an associated type whose length is a braced expression specializes with its impl, and a length that faults for a concrete instantiation is reported where it is written instead of crashing the compiler or failing with an internal error.
