Fe now supports Rust-style pipe closures with zero or more parameters, expression or block bodies, and contextual inference for omitted parameter and return types. Parameters may use the same `own`, `view`, `ref`, and `mut` modes as ordinary functions. Capture-aware closures implement `Fn` when reusable and `FnOnce` when they consume captured state, work with generic callable bounds and the functional traits in `core`, and may capture and forward effect providers. Closure, generic callable, and user-defined `Fn`/`FnOnce` values can be invoked directly with `value(args)` syntax; reusable `Fn` is preferred when both call modes apply. Closures remain unavailable in const contexts.
