Native programs receive standard output, error and input as effects. On a native target, a test or a top-level `pub fn main` takes its effects from the new root effect `std::native::Host`, as contracts take theirs from `Evm`: `pub fn main() -> i32 uses (out: mut Stdout)`. `std::io` provides the sealed capabilities `Stdout`, `Stderr` and `Stdin`, and `Stdio`, which provides all three; the builtin macros `print!`, `println!`, `eprint!` and `eprintln!`, which write the text of each `Display` argument (integers, strings, bytes, `bool`) in one unbuffered write, and `format!`, which returns it in a `MemBuffer`; `read_to_end`; and `StdinReader`, which reads standard input a byte or a line at a time. `std::env` provides `Args` (`count()`, `get(i)`) and `Env` (`lookup(name)`), and `std::process` provides `Exit` (`exit(status)`). A test or `main` that asks for an effect its target's root effect does not provide, such as `Evm` on a native target or `Stdout` on the EVM, is now a type error.
