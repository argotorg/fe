Native programs receive standard output, error and input as effects. On a native target, a test or a top-level `pub fn main` takes its effects from the new root effect `std::native::Host`, as contracts take theirs from `Evm`: `pub fn main() -> i32 uses (out: mut Stdout)`. `std::io` provides the sealed capabilities `Stdout`, `Stderr` and `Stdin`; `print`, `println`, `eprint` and `eprintln`, which write a `Display` value (integers, strings, bytes, `bool` and tuples of them) in one unbuffered write; `read_to_end`; and `StdinReader`, which reads standard input a byte or a line at a time. A test or `main` that asks for an effect its target's root effect does not provide, such as `Evm` on a native target or `Stdout` on the EVM, is now a type error.
