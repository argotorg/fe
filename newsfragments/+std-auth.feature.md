Added `std::evm::auth` with ownership and role-based access control as capabilities, after Solady's `Ownable` and `OwnableRoles`. `Ownable::authorize` checks the caller and returns an `OnlyOwner` proof, `Roles::authorize<ROLES>` returns a `Role<ROLES>` proof, and only `std` can construct them. Privileged functions declare the proof they need as an effect (`uses (minter: Role<MINTER>)`), so calling one from a path that never authorized is a compile error, provided with `with (Role<MINTER> = roles.authorize<MINTER>()) { ... }`. `Ownable` supports one-step transfer, renouncing and Solady's two-step handover with a 48-hour request window; `Roles` stores role bit sets per account that the owner grants and revokes and accounts can renounce. Errors (`Unauthorized()`, `NewOwnerIsZeroAddress()`, `NoHandoverRequest()`) and events match Solady.
