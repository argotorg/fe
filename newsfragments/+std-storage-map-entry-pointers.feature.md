`StorageMap` values may now be structs and other values that span several storage words. `map.ptr(key)` returns a read-only `StorReadPtr<V>` and `map.mut_ptr(key)` (which needs a mutable map) returns a `StorPtr<V>` to the entry; bound with `with (ptr) { ... }`, the entry is a storage place, so a single field is read or updated with one `SLOAD`/`SSTORE` instead of copying the whole value. The value is stored from `keccak256(key ++ salt)` onwards, field after field, like a struct in a Solidity `mapping`. The borrow checker knows these pointers address hashed slots, so, like single-word map entries, they never conflict with borrows of contract fields.
