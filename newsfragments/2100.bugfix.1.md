An `if` or `match` inside a tuple or variant constructor that a projection yields, as in `Option::Some(if c { mut self.a } else { mut self.b })`, no longer fails with an internal error: each branch yields its own value. What a branch that yields an access binds now lives until the caller's use of the grant ends, as the projection's other locals do, so the grant may borrow it; an element with no access, such as the `u256` of `(u256, mut T)`, is evaluated as an ordinary value.
