`fe test` on the EVM backend now compiles the selected tests of a file or ingot into one contract and deploys it once, instead of compiling and deploying each test on its own. Tests that share code no longer pay to compile it once per test: 20 tests calling a 300-function library went from 24 s to 1.1 s of CPU time. A test's call now has its 4-byte selector as calldata.
