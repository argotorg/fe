`std::wasm::Host` now provides the `std::io` streams `Stdout`, `Stderr` and `Stdin`, so code that prints with `print!` and `println!` builds for WebAssembly as well as native targets. A module imports them as `sys_wasm_stream_write` and `sys_wasm_stream_read`, which `examples/wasm/host.mjs` implements. See "WebAssembly output" in `CLI.md`.
