A `recv` arm can name a field of its message with `ref` to read it where it lies in the input instead of decoding it, such as `Cancel { ref orders } -> bool`. Such an arm reads only the fields it names: plain names are decoded, `ref` names are handles or views of the encoded data, and fields bound by `_` or `..` are not read, so malformed bytes there are accepted. The selector and the JSON ABI do not change. A `ref` field needs its type to be readable in place (`#[abi]` structs and the ABI types of the standard library are); a hand-written message type states `impl AbiFields`.
