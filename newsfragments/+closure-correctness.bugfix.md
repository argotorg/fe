Fixed borrow-checking, ownership, and runtime-lowering errors exposed by closures and nested capability-bearing values. Aggregate-held borrows, partial returns, non-`Copy` captures and patterns, capability-field rebinding, unreachable control flow, and definite initialization now preserve their source and move state consistently. Invalid programs are diagnosed before lowering, while valid nested closures and capability updates no longer panic during code generation, including unoptimized builds. Non-regular polymorphic and associated-constant recursion now report finite diagnostics instead of expanding compiler state without bound, and named function-item values—including trait and UFCS paths—lower without semantic or runtime dispatch panics. Optimized event logging also keeps the thin generic `Log::emit` delegator inlined, preserving the established deposit bytecode and gas profile.
