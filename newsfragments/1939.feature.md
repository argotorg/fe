`core::map::HashMap<K, V>` is a hash table that owns its keys and values, in the prelude. `get` gives the value in place (`mut?`), `insert` and `remove` return the old value, `get_or_insert` gives the entry's value for update (`counts.get_or_insert(word, 0) += 1`), and `map[key]` panics on a missing key. Lookups take any key type the map's key compares with, so a `DynString` key is found with a literal or a span. `for v in map` visits the values, and `keys()` and `entries()` drive loops over keys and `(key, value)` pairs. Keys implement the new `core::hash::Hash` trait, which feeds a `Hasher`; `FoldHasher` is the map's.
