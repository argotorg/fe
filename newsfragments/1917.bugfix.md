Generic arguments written in a body's paths and method calls are now checked as written types are. `take<Missing>()` and `<G<Missing> as Tr>::f()` were accepted, as was a private type in `take<m::Hidden>()`, and `G<Missing>::mk()` and `W<Missing> { x: 0 }` reported a missing method or an expected record instead of the argument's error. A shape argument in a written type, such as `Sh<(mut u256,)>`, is no longer rejected.
