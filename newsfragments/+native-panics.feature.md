Native panics now report on stderr and abort, after flushing output written before them: `panicked: arithmetic overflow` for a Solidity panic code, the message of an `assert!` that has one, other revert data in hex, and `panicked` for `core::panic`. They used to stop at a bare `SIGILL`, losing buffered output. Native `fe test` now supports `#[test(should_revert)]`, checking `panic = ...` and `selector = ...` against the revert data as on EVM. SP1 guests still trap.
