Added string to number parsing to `core::text`, matching OpenZeppelin's `Strings.tryParse*`: `parse_uint` and `parse_int` read decimal text as `u256` and signed `i256`, and `parse_hex_uint` reads hex digits of either case with an optional `0x` prefix. `std::evm::parse_address` parses `0x` and 40 hex digits (or the digits alone) into an `Address` without checking the ERC-55 checksum. All of them return `None` for invalid input, including empty text and out of range values, for which OpenZeppelin returns 0 or reverts.
