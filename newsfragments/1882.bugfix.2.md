Unchecked arithmetic now applies to every arithmetic operator written in unchecked code, whatever its operand types. On non-integer operands, `+`, `-`, `*`, `**` and unary `-` call the wrapping operator traits (`WrappingAdd`, `WrappingSub`, `WrappingMul`, and the new `WrappingPow` and `WrappingNeg`), and `x += y` assigns `x.wrapping_add(y)`. `Wei`, `Duration` and `Timestamp` implement these traits, so their operators wrap in unchecked code instead of reverting with `Panic(0x11)`; a type used with these operators in unchecked code must implement them too. Called functions keep their own arithmetic mode, including generic functions and explicit calls such as `x.add(y)`, and a closure has the mode of the function it is written in.
