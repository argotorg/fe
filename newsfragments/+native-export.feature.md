`#[export]` on a free `pub fn` makes a native build define the function under its own name with the C calling convention, kept even when nothing in Fe calls it, so C or Rust code linked with the build can call it. An exported function cannot be generic or take `uses` effects, and its parameters and result must be `i32`, `u32`, `i64`, `u64`, `usize`, `isize` or raw pointers. EVM and SP1 builds reject `#[export]`.
