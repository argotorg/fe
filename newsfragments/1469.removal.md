Removed the old integer-address and wrapper-based memory surface, including `MemPtr<T>`, `core::abi::MemoryInput`, `std::evm::MemoryBytes`, `std::evm::mem::alloc`, and the cursor-based `AbiEncoder` API. Migrate typed memory addresses to `*T`, read-only memory regions to `MemSpan`, and owned or writable allocations to `MemBuffer`. The unused `core::convert::Into<T>` trait was also removed; use explicit conversion APIs instead.
