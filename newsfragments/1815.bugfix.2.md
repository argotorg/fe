Find references, rename, highlighting, code lens reference counts and the SCIP and LSIF indexes now resolve an unlabeled `uses` entry of a contract's `init` or recv arm, such as `uses (mut state)`, as the compiler does: to the contract field, or to an effect of the contract's own `uses`. An item of the same name in scope was taken instead, so renaming a function named like one of the contract's effects rewrote the entry.
