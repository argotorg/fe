Added `std::evm::random` with pseudorandom numbers as an effect, after Solady's `LibPRNG`. Code that needs randomness declares `uses (rng: mut Rng)` and the caller provides a generator with `with (Rng = ...)`: `KeccakRng` reproduces Solady's keccak256 chain from a seed such as `ctx.prevrandao()`, and `ReplayRng` returns chosen words so tests can drive the same code to specific outcomes. `Rng` provides `next`, unbiased `uniform` and `chance`, and the generic `shuffle` (arrays), `shuffle_slice` (`MemSlice`) and `choose` work for any element type.
