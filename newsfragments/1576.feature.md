Support boolean const `where` predicates on items, such as `fn operation() where allowed(3) {}` and `const fn bounded<const N: usize>() where N > 0`. Conditions without generic parameters are evaluated where they are declared, even if the item is unused. Conditions on a generic function are checked at every use after inference, and a generic caller satisfies one only by stating the same condition. Const predicates on generic types, traits, impls and associated functions are rejected for now.
