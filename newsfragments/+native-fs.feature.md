`std::fs` gives native programs on Linux and macOS the host's files and directories through the sealed capability `Fs`, which `main` and tests take from `std::native::Host`: `uses (fs: Fs)` to read and `uses (fs: mut Fs)` to also change files. `Fs` provides `read`, `write`, `append`, `create_dir_all`, `metadata` (file type and size), `read_dir` (entry names and types) and `canonicalize`. A path is any `Display` value. A failure returns an `Error` holding the host's `errno`, which `kind()` classifies (`NotFound`, `PermissionDenied`, `AlreadyExists`, `NotADirectory`, `IsADirectory`, `InvalidInput`, `Other`) and which displays as the host's message.
