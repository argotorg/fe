`fe build --backend wasm` now builds ingots and workspaces as well as single files. An ingot is one module, which exports the functions marked `#[unsafe(export)]` anywhere in the ingot, as a native library does; they may call the rest of the ingot and its dependencies. A workspace build writes one module per member with exports, and `--ingot <name>` selects one member. `--wasm-stack-size <bytes>` sets the stack size, 1 MiB by default. Released `fe` binaries now include the WebAssembly backend.
