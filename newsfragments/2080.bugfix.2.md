`core::intrinsic::storage_slots<T>()` of a type that names a parameter, such as `T`, a trait's `Self` or `[u256; N]`, is now counted at each instance. Before, a const using it, such as an array length, counted such a type as one slot, and a generic function calling `storage_slots<[u256; N]>()` was rejected with error 16-0010.
