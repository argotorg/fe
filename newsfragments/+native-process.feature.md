`std::process` runs other programs on Linux and macOS through the sealed capability `Spawn`, which `main` and tests take from `std::native::Host` with `uses (proc: mut Spawn)`. A `Command` names the program and sets its arguments, environment (`env`, `env_remove`), directory, standard streams and timeout: `proc.output(Command::new("git").arg("status").stdout(Redirect::Capture))`. Standard input is inherited, `Null` or `Bytes`; standard output and error are inherited, `Null`, captured, written to a `File`, or, for standard error, sent to standard output. `spawn` starts a `Child` and `wait` waits for it, while `wait_any` serves several children at once and returns the index of one that has ended. An `Output` holds the `Status` (an exit status, a signal, or `TimedOut`), the captured bytes, and the `Usage`: user and system CPU time and peak resident memory. A failure returns a `std::io::Error`.
