Added `std::evm::SolArray` and `std::evm::SolEnumerableSet` for Solidity dynamic storage arrays (`T[]`, with small elements packed like Solidity and Solidity's `Panic` codes) and OpenZeppelin `EnumerableSet` storage at runtime slots. `SolSlot::load` returns a `SolWord` for reading or updating several packed fields of a slot with a single `sload`/`sstore`.
