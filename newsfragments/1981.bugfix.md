Optimized code no longer moves a division, a constant table read or an address computation ahead of the test that guards it: `if d != 0 { s += x / d }` in a loop could trap with `d == 0` on native and WebAssembly targets at `-O1` and above. On WebAssembly, an import that throws no longer leaks the module's stack. A module with imports exports its `stack_top` global, and a host restores it after a call fails; this is version 2 of the host contract, which `examples/wasm/host.mjs` implements.
