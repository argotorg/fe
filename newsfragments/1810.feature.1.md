`MemVec<T>` (in the prelude) is now a growable array of Fe values in memory, for any element type, including non-`Copy` ones such as `MemBuffer`. Create one with `MemVec::new()` or `with_capacity`, then use `push`, `pop`, `reserve`, `truncate`, `extend_from_slice`, `get`, `get_mut`, `set`, `replace`, `swap`, indexing, `for` loops (including `for mut x in v` and `v.reversed()`), the `core::sort` functions and `MemVec::collect`. `into_array` turns it into a fixed-length `MemArray` without copying. `DynArray::from_slice` ABI-encodes the elements of a slice such as `v.as_slice()`, and `DynArray::to_mem_array` decodes an array into a `MemArray`.
