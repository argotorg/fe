Associated types can take their own type parameters, as in `trait Factory { type Pair<T> = (T, bool) }`. A trait can give such a type a default, and an impl can override it with a definition over the same parameters. Uses write the arguments, as in `F::Pair<T>` or `<S as Inner<V>>::Pair<bool>`. A bound on a parameter (`type Out<T: Show>`) must hold wherever the type is used. A bound on the associated type itself (`type Out<T>: Show`) is checked once, for every argument the parameter bounds allow, and generic code can then rely on it. Without its arguments, such a type can be passed where a type constructor is expected, unless its parameters have bounds.
