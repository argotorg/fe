Added `std::evm::eip712` with `DOMAIN_TYPEHASH`, `domain_separator`, a `digest` that needs no effects, and a `Domain` type that caches the separator in an immutable contract field and derives it anew when the chain id or executing address differs, matching OpenZeppelin's `EIP712`. `std::evm::crypto::eip712_digest` now uses the same direct 66-byte hashing, saving about 1,600 gas per call, and no longer requires the `RawMem` effect.
