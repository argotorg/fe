Generation works in packages. `fe check`, `fe build`, `fe test` and the language server run the providers of a package and of the packages it depends on, dependencies first, and check the result. A provider can be written in a dependency, a header can be written in any file of a package, and what a dependency generates is an ordinary item for the packages that depend on it. A provider does not read what its own package generates. See `docs/language/generation.md`.
